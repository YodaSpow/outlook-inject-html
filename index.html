First time installing?
  1. Enter chrome://extensions/ in Chrome’s address bar.
  2. Turn on Developer mode using the switch at the upper right.
  3. Use the local-install control specified by the eventual package instructions.

Menu route: Extensions menu → Manage Extensions.

Work or school-managed Chrome may restrict manual extension installation.
